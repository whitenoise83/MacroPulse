MacroPulse Model 1C v0.4.0 upgrade

1. Extract this package into the MacroPulse project root and replace files.
2. Preserve .env, .git, data/macropulse.duckdb, and reports/.

   pip install -e .
   python scripts\initialise_database.py
   python scripts\evaluate_labour_policy.py --backtest-id 834e0655-ba81-4b96-b42c-e1cdda73b847

This release makes no FRED requests and does not rerun the vintage backtest.
