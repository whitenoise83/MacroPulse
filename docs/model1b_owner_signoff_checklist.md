# Model 1B owner-signoff checklist

Before approving a production freeze, review:

1. The candidate validation report and all 28 passing gates.
2. The governed-live operational report and all 20 passing gates.
3. The latest four headline forecasts and their target periods/stages.
4. The stable target-stage policy and shadow-only adaptive selector.
5. The `exp_weighted_q80` interval method and prior-error counts.
6. The comparable news decomposition and zero/immaterial reconciliation residual.
7. Configuration, code, information-set, model-state, and governance hashes.
8. Known limitations in the Model 1B model card.

Owner approval should be explicit and version-specific. The freeze assessment itself
does not promote Model 1B to production.
