---------------------------------------

could not use the user's FRED API key. Therefore the following must be validated
on the user's existing MacroPulse environment:
- DuckDB schema migration against the existing database.
- Live FRED historical-snapshot downloads.
- Streamlit rendering with the user's stored runs.

The package preserves the existing database and does not contain .env, API keys,
DuckDB files, WAL files, or cached FRED data.
